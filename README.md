# Customer Attrition Prediction

## Project Overview

This project uses machine learning to predict customer attrition
based on various customer network usage information. The Dataset was downloaded on kaggle hub with aim of giving data scientists a project to work on improving and testing their skills

## Objectives

- Explore the dataset using Exploratory Data Analysis (EDA).
- Identify relationships between features and Attrition column containing binary values (Yes/No).
- Handle missing values and categorical variables.
- Train and evaluate a machine learning model.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Data collection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Feature engineering
5. Model training using Logistic Regression
6. Model training using Decision trees
7. Model training using Random Forest 
8. Model evaluations

## Results

1. The model performed very well on Logistic Regression after assigning weights to classes and overfitting was fairly low
2. The model performed fairly poor on Decision trees even after parameter tuning but atleast the ability to predict the Yes class improved a little, the model overfitted due to the size of the dataset
3. The Random Forest Model performed very poor due to the size of the dataset


## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Open the Jupyter Notebook.
4. Run the notebook cells.
